# Propuestas Díptico NOVA

Static viewer of the six design proposals for the Campus NOVA (Centro Cristiano Educativo) enrollment-2027 brochure. Review mock-up, not an approved piece. Photos marked as illustrative are AI-generated.

This repository is a publish-only copy. The source lives in the private `cce-campus-nova` repo; regenerate it with `python proyectos/diptico-presentacion/visor/export-sitio.py <this-folder>`.

Works on any static host (GitHub Pages, Netlify, Cloudflare Pages, a plain web server). No build step.
